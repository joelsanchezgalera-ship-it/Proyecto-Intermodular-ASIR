# 1. Introducción
## 1.1. Título del reto
Desarrollo e implementación de una aplicación web funcional para TransNova Logistics, conectada a una base de datos y desplegada mediante un servidor Apache.

## 1.2. Contexto
En la actualidad, el crecimiento del comercio electrónico ha aumentado la demanda de servicios de transporte y logística rápidos, seguros y trazables. Para competir en este entorno, las empresas del sector no solo requieren una operativa física de transporte, sino una infraestructura informática sólida que garantice la gestión fluida de clientes, solicitudes de envíos y la continuidad del negocio.
