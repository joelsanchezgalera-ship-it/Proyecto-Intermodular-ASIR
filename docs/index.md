# TransNova Logistics

Bienvenido a la documentación del proyecto de **TransNova Logistics**.

En este proyecto se desarrolla una aplicación web funcional para una empresa de transporte y logística, conectada a una base de datos y desplegada mediante un servidor Apache.

La documentación recoge el desarrollo, la configuración de los servicios y las pruebas realizadas durante el proyecto de 2.º ASIR.
